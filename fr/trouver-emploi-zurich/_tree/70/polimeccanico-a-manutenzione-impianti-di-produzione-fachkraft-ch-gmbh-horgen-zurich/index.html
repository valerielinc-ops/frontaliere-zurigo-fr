Description complète

Les perturbations de la production sont rapidement corrigées dans les usines modernes. Ce faisant, vous effectuez des travaux de maintenance dans le cadre d'opérations permanentes et de vérifications professionnelles. Pour notre client, nous recherchons une ou plusieurs activités

  • Résoudre rapidement les défauts de production sur les usines
  • Réviser les usines professionnellement
  • Effectuer des travaux d'entretien en cours
  • Fabrication de pièces détachées et de pièces neuves sur les machines-outils
  • Prendre en charge le pikett et le service de défaillance
  • Exigences
  • Formation technique de base terminée
  • Expérience dans l'entretien des équipements de production
  • Pratique dans l'entretien des équipements techniques
  • Connaissance de l'usinage conventionnel avec tournage, fraisage, forage
  • Très bonne expertise en pneumatique et hydraulique
  • Large gamme
  • Tâches dans un environnement de production moderne - Beaucoup de responsabilités dans le domaine de travail quotidien - Conditions appropriées
