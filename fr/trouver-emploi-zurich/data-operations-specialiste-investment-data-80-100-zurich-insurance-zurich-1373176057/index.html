Description complète

Voulez-vous que vos compétences en matière de données aient un impact réel sur les décisions d'investissement?

Dans ce rôle de Data Operations Specialist – Investment Data , vous travaillerez côte à côte avec trois membres d'équipe expérimentés et solidaires qui sont passionnés par des plateformes de données robustes et bien conçues. Vous aiderez à exécuter et améliorer notre entrepôt de données d'investissement, surveiller et optimiser les pipelines de données quotidiens à Azure, et assurez-vous que nos utilisateurs ont des données propres et cohérentes à portée de main.

Vous aurez la chance de creuser profondément dans les données d'investissement, d'affiner vos compétences SQL et d'automatisation, et de développer votre expérience avec des outils de données cloud modernes. Si vous aimez prendre possession, collaborer étroitement avec les utilisateurs d'affaires et améliorer continuellement comment les choses sont faites, nous serions heureux d'entendre de vous

Ce que vous ferez

  • Maintenir et développer l'entrepôt de données d'investissement dans un environnement SQL Server.
  • Surveillez les pipelines de données quotidiens dans Azure Data Factory et d'autres solutions.
  • Assurer une qualité élevée des données en utilisant le cadre automatisé.
  • Utilisation des contrôles de qualité des données et des tableaux de bord
  • Enquêter sur les écarts et les résoudre systématiquement.
  • Réalisation du rapprochement des données
  • Résoudre les problèmes opérationnels et les questions (p. ex. optimiser les requêtes, les données manquantes, vérifier la cohérence)
  • Interagir avec les utilisateurs pour comprendre les exigences et améliorer leur expérience utilisateur de données
  • Tenir à jour la documentation technique

Ce que vous apportez

  • 2 à 3 ans de travail dans les opérations de données, l'administration du soutien aux BI ou l'administration des entrepôts de données (p. ex. soutien des plateformes de données existantes, des emplois prévus et des rapports).
  • Expérience dans un environnement de production, notamment :
  • Surveillance quotidienne des charges et interfaces de données
  • Traitement des incidents et demandes de services
  • Coordination avec les utilisateurs et les autres membres de l'équipe.

Connaissance du domaine

  • Expérience dans l'industrie des services financiers ou dans une industrie ayant des exigences similaires
  • Bonne compréhension des données sur les investissements (p. ex. titres, émetteurs, indices) et des structures connexes (p. ex. portefeuilles, participations, hiérarchies d'entreprises)

Compétences techniques

  • Fortes compétences pratiques en SQL pour valider les données, l'optimisation des requêtes / réglage des performances, et résoudre les problèmes.

Familiarité avec les environnements SQL Server et les concepts d'entrepôt de données (tables et structures de navigation confortables).

  • Connaissances de travail de Azure Data Factory et/ou Databricks: surveiller les pipelines et les activités; redémarrer / refaire les travaux échoués, lire les journaux et identifier les problèmes.
  • Connaissance pratique des plateformes de données en nuage (p. ex. Databricks, Microsoft Fabric) pour l'exécution des tâches, la vérification de l'état et le dépannage.
  • Compétences de script en Python pour l'automatisation et les tâches opérationnelles (par exemple, analyse de log, petits utilitaires). R est un bon à avoir
  • Connaissance pratique de Power BI : développement et maintien de modèles sémantiques dans Power BI, validation de données dans le modèle et mise en œuvre de tableaux de bord
